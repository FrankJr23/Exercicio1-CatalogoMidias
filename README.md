<h2>Modelagem de Sistemas - Noções de POO</h2>

<p>Esta atividade tinha o objetivo de praticar conceitos de POO</p>

<h3>Objetivo</h3>
Colocar em prática os conceitos estudados nas aulas de Programação Orientada a Objetos
(POO) em Java:
- Criação e uso de objetos
- Encapsulamento (get/set)
- Construtores e sobrecarga
- Herança e polimorfismo
Cada aluno ou grupo deverá desenvolver um dos três exercícios abaixo e publicar o projeto
no GitHub.

<h3>Exercício 1 – Catálogo de Mídias</h3>
Desenvolva um sistema simples para gerenciar um catálogo de filmes e séries. O sistema
deve permitir cadastrar e exibir informações no console.
Requisitos
- Criar uma classe base Midia com: titulo, anoLancamento, genero, métodos get e set com
validação, e método exibirResumo().
- Criar as subclasses: Filme (duracaoMinutos) e Serie (temporadas e
episodiosPorTemporada).
- Aplicar encapsulamento, construtores e sobrecarga, herança e polimorfismo (sobrescrever
exibirResumo()).
- Criar a classe principal App para instanciar filmes e séries e exibir as informações no
console.
